# turn-based-rouge-lite-game

A personal project using vanilla javascript to create a turn-based rouge-lite game with fantasy themes. This project was started to attempt to learn 2D game development using HTML5 canvas with the goal of having a functional gameplay loop.

Assets used and their sources:

- https://zerie.itch.io/tiny-rpg-character-asset-pack

- https://zerie.itch.io/tiny-rpg-character-asset-pack-02
